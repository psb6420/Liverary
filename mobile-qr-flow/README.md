# Liverary QR 모바일 흐름 시안

기존 통합 화면과 분리한 스마트폰 전용 프로토타입이다. QR을 스캔해 접속한 뒤 사용자 화면에서 일어나는 과정만 390×844px 비율로 구성했다.

## 화면 흐름

1. QR 인식
2. 좌석 이용 시작 및 집중 시작 대기
3. 집중 시작
4. 일시정지·재개
5. 종료 확인
6. 오늘 기록
7. SNS 카드 저장·공유

QR 인식 시 좌석 이용시간만 시작한다. 집중시간은 사용자가 `집중 시작`을 눌러야 기록되며, 일시정지 중에는 집중시간만 멈추고 좌석 이용시간은 계속 흐르는 방식이다.

좌석 시작시각, 실제 집중 구간, 일시정지 횟수와 완료 기록은 브라우저 `localStorage`에 저장된다. 새로고침하거나 화면을 잠갔다 돌아와도 실제 시각을 기준으로 이어지며, 오늘 누적은 완료된 집중 구간을 합산한다.

실제 QR에는 다음과 같은 URL을 넣을 수 있다.

```text
http://127.0.0.1:4174/mobile-qr-flow/?qr=1&library=미래도서관&floor=2층&zone=창가%20자유석
```

## 디자인 기준

- 팀원 원본 `Liverary.html`의 `#5650dc` 보라색, `#eeedfe` 라벤더, 흰 카드와 얇은 회색 테두리를 사용했다.
- 데스크톱에서는 390×844px 스마트폰 프레임으로 보이고, 실제 스마트폰에서는 전체 화면으로 전환된다.
- SNS 카드 미리보기 자체를 1080×1350 Canvas로 그리며, `이미지 저장`과 모바일 공유는 화면에 보인 동일 Canvas를 사용한다.

## 곰두리 사용 안내

시안에는 [강원대학교 공식 곰두리 기본형 이미지](https://www.kangwon.ac.kr/assets/ko/images/sub/mascot2.png)를 `assets/gomduri.png`에 보관해 화면과 공유 카드에 동일하게 사용한다. 공식 페이지는 상업적 이용에 별도 허락이 필요하고, 물품 제작 및 행사 이용 시 승인을 요구한다고 안내한다.

- [곰두리 공식 소개 및 이용 안내](https://www.kangwon.ac.kr/ko/conts/917/web.do)
- 현재 결과물은 수업 및 내부 검토용 시안 기준이다.
- 창업대회 제출, 외부 배포 또는 실제 서비스 공개 전에는 강원대학교 담당 부서에 사용 범위를 확인해야 한다.
