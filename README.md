# Liverary prototype

기획서 `Liverary_Project_Proposal.docx`의 단일 자유열람실 가상 대시보드와 액션 뷰를 구현했습니다.

`Liverary.html`을 편집할 때는 `python dev_server.py`로 로컬 미리보기를 실행하세요. `http://127.0.0.1:4173/`에서 해당 파일을 보여주며, 저장하면 브라우저가 자동 새로고침됩니다. 서버를 끄려면 실행 중인 터미널에서 `Ctrl+C`를 누르세요. 배포나 별도 패키지 설치가 필요하지 않습니다. 정적 배포용 파일은 `Liverary.html`입니다.

## 구현
- 48석 좌석 지도, 상태 표시, 창가/콘센트/빈자리 필터
- 후면 카메라 QR 스캔 체크인 및 카메라 미지원/거부 시 좌석 번호 입력 대체
- QR 체크인 뒤 위치 권한 요청, 도서관 또는 체크인 좌석 범위 밖 30분 지속 시 자동 이용 종료
- 단일 이용자 세션, 이석/복귀/이용 종료, 만료 시 공석 전환
- 태그 좌석 신고 시 알림과 유예, 미태그 신고 시 즉시 공석 및 수거 경고
- 잘못 표시된 빈자리의 사용 중 상태 수정
- 가상 밀집도, 시간 진행, 초기화, 브라우저 로컬 저장

## 프로토타입 가정
실제 도서관 도면·좌석 수·센서 값이 아닌 예시입니다. 카메라는 사용자가 QR 체크인을 눌렀을 때만 요청하며, HTTPS 또는 localhost에서 열어야 합니다. QR 판독은 브라우저 기본 기능을 우선 사용하고 미지원 브라우저에서는 앱에 포함된 jsQR로 처리합니다. 카메라 권한이 없으면 좌석 번호를 직접 입력할 수 있습니다. 카메라 영상은 기기에서 QR을 찾는 동안만 사용하고 서버로 전송하지 않습니다. 위치도 QR 체크인 이후에만 요청하며 브라우저 로컬 저장소에서만 사용합니다. 실제 도서관 좌표가 QR에 없다면 체크인 위치를 도서관 기준점으로 삼고, 좌석 35m 또는 도서관 250m 범위 안에 있으면 재실로 판단합니다. 위치 권한이 거부되거나 정확도가 100m보다 낮으면 자동 종료를 실행하지 않습니다. 좌석 QR URL에는 `seatLat`, `seatLng`, `seatRadius`, `libraryLat`, `libraryLng`, `libraryRadius`를 넣어 기준점을 지정할 수 있습니다. jsQR 배포 파일과 Apache-2.0 라이선스는 `dist/vendor/`에 있습니다. 서버, 다중 사용자 동기화, 통신사 API, 외부 푸시 알림, AI 모델, 실제 물품 수거는 연결하지 않았습니다.

기획서의 기존 15분 보호안은 요청에 따라 30분으로 통일했습니다. 데모는 혼잡도에 따라 기본 이용 시간만 여유 180분, 보통 120분, 혼잡 90분으로 바뀌며, 이석·신고·도서관 또는 좌석 범위 이탈 유예는 모두 30분입니다. 세션 시작 시 기본 이용 시간을 고정하며 기존 이석 보호는 신고로 늘어나지 않습니다. 기기 밀집도는 좌석 점유율과 다른 입력이며 실측 혼잡도를 뜻하지 않습니다.

실운영 전에 센서 가용성·개인정보 처리, QR 인증·현장 검증, 신고 남용 방지 및 도서관의 물품 처리 규정 확정이 필요합니다.
