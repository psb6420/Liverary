# Liverary prototype

기획서 `Liverary_Project_Proposal.docx`의 단일 자유열람실 가상 대시보드와 액션 뷰를 구현했습니다.

`dist/index.html`을 열거나 `python -m http.server 4173 --directory dist`로 실행합니다. 별도의 설치/빌드가 필요하지 않습니다.

## 구현
- 48석 좌석 지도, 상태 표시, 창가/콘센트/빈자리 필터
- 후면 카메라 QR 스캔 체크인 및 카메라 미지원/거부 시 좌석 번호 입력 대체
- 단일 이용자 세션, 이석/복귀/이용 종료, 만료 시 공석 전환
- 태그 좌석 신고 시 알림과 유예, 미태그 신고 시 즉시 공석 및 수거 경고
- 잘못 표시된 빈자리의 사용 중 상태 수정
- 가상 밀집도, 시간 진행, 초기화, 브라우저 로컬 저장

## 프로토타입 가정
실제 도서관 도면·좌석 수·센서 값이 아닌 예시입니다. 카메라는 사용자가 QR 체크인을 눌렀을 때만 요청하며, HTTPS 또는 localhost에서 열어야 합니다. 브라우저 QR 판독 API가 지원되지 않거나 카메라 권한이 없으면 좌석 번호를 직접 입력할 수 있습니다. 카메라 영상은 기기에서 QR을 찾는 동안만 사용하고 서버로 전송하지 않습니다. 서버, 다중 사용자 동기화, 통신사 API, 외부 푸시 알림, AI 모델, 실제 물품 수거는 연결하지 않았습니다.

기획서는 기본 15분 보호와 50% 미만/80% 이상 동적 정책만 제시합니다. 데모는 여유 180분/20분, 보통 120분/15분, 혼잡 90분/10분을 임시 채택했습니다. 세션 시작 시 정책을 고정하며 기존 이석 보호는 신고로 늘어나지 않습니다. 기기 밀집도는 좌석 점유율과 다른 입력이며 실측 혼잡도를 뜻하지 않습니다.

실운영 전에 센서 가용성·개인정보 처리, QR 인증·현장 검증, 신고 남용 방지 및 도서관의 물품 처리 규정 확정이 필요합니다.
