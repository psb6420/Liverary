# Liverary

Liverary는 도서관 자유열람실의 빈자리를 확인하고, 좌석 QR 체크인과 이석 관리를 체험할 수 있는 웹 프로토타입입니다. 실제 도서관 좌석·센서·예약 시스템과 연결되지 않은 데모입니다.

## 주요 기능

- 48석 좌석 지도와 사용 가능·사용 중·이석 상태 표시
- 빈자리, 콘센트, 창가 조건 필터
- 카메라 QR 스캔 또는 좌석 번호 입력을 통한 체크인
- QR 체크인 뒤 위치 권한 요청
- 도서관 또는 체크인 좌석 범위 밖에 30분 연속 머무르면 자동 이용 종료
- 잠깐 이석, 복귀, 이용 종료와 방치 좌석 신고 흐름
- 이석·신고 유예 시간 30분 적용
- 혼잡도에 따른 기본 이용 시간 시뮬레이션

## 사용 방법

`Liverary.html`은 별도 빌드 과정 없이 사용할 수 있는 단일 파일 프로토타입입니다. 카메라와 위치 권한을 사용하려면 브라우저의 보안 컨텍스트(HTTPS 또는 localhost)에서 열어야 합니다.

QR에는 좌석 번호만 넣을 수 있으며, URL 형태의 QR에는 다음 값을 추가해 좌석과 도서관의 위치 기준점을 지정할 수 있습니다.

`seat`, `seatLat`, `seatLng`, `seatRadius`, `libraryLat`, `libraryLng`, `libraryRadius`

예시: `https://example.org/checkin?seat=A01&libraryLat=37.0000&libraryLng=127.0000`

## 위치 및 개인정보

위치 정보는 QR 체크인 이후에만 요청하며 브라우저 로컬 저장소에서만 사용합니다. 위치 권한이 거부되거나 정확도가 100m보다 낮으면 위치 기반 자동 종료를 실행하지 않습니다. 카메라 영상과 위치 정보는 서버로 전송하지 않습니다.

## 정책

기본 이용 시간은 혼잡도에 따라 여유 180분, 보통 120분, 혼잡 90분으로 달라집니다. 이석, 신고, 도서관 또는 좌석 범위 이탈에 대한 유예 시간은 모두 30분입니다.
