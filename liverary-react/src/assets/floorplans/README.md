# 미래도서관 1층 배치도

## 현재 목업: ④ We플레이스

- `we-place-layout.svg`: 창가 바·소파·작은 테이블·큰 테이블의 자유석 번호 01–14와 24–51을 표시한 배치도, 1200 × 1500. PC는 선택 불가 참고 영역이다.
- `we-place-background.svg`: 같은 도식에서 정적 좌석 표식을 뺀 React 배경 자산
- `WePlaceMap.jsx`: 배경 위에 실제 클릭 가능한 좌석 버튼을 배치한다. 상태·필터는 React 모델을 따른다.
- `src/lib/wePlace.js`: 활성 자유석 42개 ID·그룹·좌표와 배치도 크기·마커 지름을 관리한다. 기존 W01–W14와 W24–W51은 유지하고 PC W15–W23은 `RETIRED_PC_SEATS`로 따로 보존한다.
- `reference/we-place-vr-*.png`: 사용자가 제공한 VR 참고 화면 4장

사진 기준으로 구성한 자유석 목업은 총 42개 선택 지점이다. 사용자 설명에 따라 좌측 PC 예약석 9개는 서비스 대상에서 제외한다. 창가 바 6개, 파란 유선형 공통 소파 8개, 작은 테이블 16개, 큰 테이블 6개, 개별 소파 6개를 이용 지점으로 표현했으며 학교가 확인한 공식 정원이 아니다. PC 이외의 회색 가구도 번호 표식이 있으면 선택 대상이다.

| 좌석 | 그룹 ID | 표시 이름 | 선택 가능한 수 |
|---|---|---|---|
| 01–06 | `window-bar` | 창가 바 · 콘센트 | 6 |

| 이전 15–23 | `pc-row`(이력용) | PC 예약석 · 서비스 제외 | 0 |
| 24–27 | `small-table-1` | 작은 테이블 1 | 4 |
| 28–31 | `small-table-2` | 작은 테이블 2 | 4 |
| 32–35 | `small-table-3` | 작은 테이블 3 | 4 |
| 36–39 | `small-table-4` | 작은 테이블 4 | 4 |
| 40–45 | `large-table` | 큰 흰 테이블 | 6 |

공식 전체 1층 안내도와 VR 화면을 참고해 상대적 배치만 재구성했다. PC 공간은 왼쪽에, 작은 테이블 네 묶음은 그 앞에 놓는다. 큰 흰 테이블 한 개는 ③ 브라우징 밸리 쪽에 두고 연결된 U자 소파에 6개의 임시 이용 지점을 배분한다. 바는 오른쪽 짧은 곡선 창면에 놓는다. 두 파란 소파는 타일 로비의 베이지 매트 위에서 사선으로 떨어진 구성을 표현한다.

개별 소파는 사진에 보이는 세 쌍의 6개를 반영해 PC 반대편 오른쪽 직선 창면에 놓았다. 앞선 논의의 8개를 확정한 수량은 아니다. 42개 활성 이용 지점의 번호와 가구별 분할은 프로젝트 체험용이며 학교 공식 번호·정원·예약 가능 수량을 의미하지 않는다. 정확한 거리·방위·가구 치수를 확인한 실측 도면도 아니다.

현재 배치도 좌표계는 `viewBox="0 0 1200 1500"`이다. 좌석 클릭 영역은 지름 80의 원형이며 `clip-path: circle(50%)`로 실제 클릭 영역도 원형으로 제한한다. 창가 좌석의 내부 표식은 둥근 사각형으로 구분한다. `model.test.js`는 활성 번호·그룹·좌표 범위와 원형 마커 간격, 이전 14석 및 PC 포함 저장 데이터의 기록·진행 세션 보존을 검사한다. 이는 브라우저에서의 배경 정렬·클릭·확대 검수를 대신하지 않는다.

PC W15–W23은 선택 목록·QR 생성·신규 세션·자유석 집계에서 제외한다. 과거 PC 기록은 조회할 수 있고 진행 중인 PC 세션은 이어서 종료할 수 있다. 다른 좌석 ID를 PC 번호로 다시 채우지 않아 예전 QR과 기록이 다른 좌석으로 바뀌지 않는다.

확대 범위는 100% 전체보기부터 최대 400%다. 전체보기는 상대 위치 확인용으로 모바일에서 좌석 선택 영역이 작다. 좁은 화면에서는 300% 이상 확대해 44px 이상의 클릭 영역을 확보하는 것을 기준으로 한다. PC 제외 수정본의 320·360·390·430px 검수에서 활성 표식 42개·PC 표식 0개, 목록·QR 옵션의 PC 제외와 배경 로딩을 확인했다. 300% 선택 영역 지름은 각각 57.19·65.19·69.59·77.59px다. PC query/hash 주소의 홈 반환과 자유석 24번의 이용·집중·종료·기록 저장도 확인했다. 이전 PC 포함 51개 검수 결과를 이번 수정본에 그대로 적용하지 않는다. 기존 PC 기록·진행 세션의 UI 복원은 이번 브라우저 검수에 포함하지 않았으며 보존·종료 규칙은 모델 테스트로 확인했다.

`future-library-1f-plan.*`는 앞서 만든 전체층 참고도다. 현재 React 목업 대상은 ① 카페가 아니라 ④ We플레이스다.

## 앞선 전체층 참고도

`future-library-1f-plan.svg`는 먼저 제작한 전체층 참고도다. 전체 1층을 표시하고 당시 범위인 **① 카페(Stay by Us)**를 보라색으로 강조했다. 현재는 참고 자산으로만 보관한다.

## 기준과 범위

- 공식 안내도의 상대적 공간 배치를 가로형 2D 도식으로 단순화했다. 건축 설계도면이나 실측 도면이 아니다.
- ① 카페는 왼쪽, ② 링크미디어 스페이스는 오른쪽 상부, ③ 브라우징 밸리는 오른쪽 중간, ④ We플레이스는 오른쪽 하부에 놓았다.
- 중앙 통로, 상부 실내 구획, 테라스와 조경은 위치를 파악하기 위한 참고 요소다.
- ③의 단차·라운지는 브라우징 밸리이며, 상하층 이동 계단으로 표기하지 않았다.
- 카페 실내와 파라솔·조경 영역을 구분했다. 원본의 검은 사각 공간은 용도를 확인하지 못했으므로 좌석을 배치하지 않았다.
- **전체층 참고도의 가구군은 도식화했다.** 표시한 카페 테이블·의자 수가 실제 좌석 수를 나타내지는 않는다. 카페 현장 조사표의 51석을 추정해 배치하지 않았으며 이 전체층 파일에는 개별 좌석 번호도 부여하지 않았다. 현재 ④ We플레이스의 체험용 자유석 42개 이용 지점과는 별개 자료다.
- 원본에 치수·축척·방위·개별 좌석 좌표가 없다. 실제 이용 화면의 좌석 표식은 현장 위치를 확인한 뒤 추가한다.

## React 연동용 그룹

SVG의 좌표계는 `viewBox="0 0 1600 1000"`이다.

| 그룹 ID | 공간 | 전체층 참고도 제작 당시 강조 범위 |
|---|---|---|
| `zone-01-cafe` | ① 카페 | 예 |
| `zone-02-media` | ② 링크미디어 스페이스 | 아니오 |
| `zone-03-browsing-valley` | ③ 브라우징 밸리 | 아니오 |
| `zone-04-we-place` | ④ We플레이스 | 아니오 |

`data-mockup-enabled` 속성은 앞선 제작 당시의 ① 구역을 구분한다. 이 전체층 파일은 정적 참고도이며, 현재 React 좌석 선택 화면은 별도의 We플레이스 자산을 사용한다.

`source-empty-area`는 ① 강조 범위 안의 용도 미확인 공간이다. `data-seat-enabled="false"`로 표시했으며, 후속 좌석 선택 화면에서도 클릭 대상에서 제외한다.
