## ④ We플레이스 좌석배치도

- 저장 파일: `floorplans/we-place-layout.svg`(번호 포함), `floorplans/we-place-background.svg`(React 좌석 버튼 아래 배경)
- 기준 자료: 강원대학교 도서관의 공식 전체 1층 안내도와 사용자가 제공한 미래도서관 VR 가상체험 We플레이스 화면 4장
- 로컬 참고 원본: `floorplans/reference/we-place-vr-window.png`, `we-place-vr-sofa.png`, `we-place-vr-table.png`, `we-place-vr-lounge.png`
- 기준 수량: PC 예약석 9개를 제외한 자유석 목업 이용 지점 42개. 창가 바 6개 + 파란 공통 소파 8개 + 작은 테이블 16개 + 큰 흰 테이블 6개 + 개별 소파 6개다. 학교가 확인한 공식 정원이 아니다.
- 현재 선택 번호는 01–14와 24–51이다. 좌석 분할·세부 위치는 체험용이며 학교 공식 번호·정원·예약 가능 수량·실측 치수를 의미하지 않는다.
- 01–06번 콘센트 정보는 사용자의 현장 설명을 반영한다. 다른 좌석의 콘센트 유무는 확인되지 않아 표시하지 않는다.
- 좌석 그룹: 01–06번 `window-bar`, 07–10번 `sofa-1`, 11–14번 `sofa-2`, 24–39번 `small-table-1`–`small-table-4`, 40–45번 `large-table`, 46–51번 `armchair-1`–`armchair-3`
- PC는 사용자 설명에 따라 서비스 대상에서 제외하며 왼쪽의 참고 영역으로만 남긴다. 이전 `pc-row`의 W15–W23 ID는 과거 기록·진행 세션 보존용이며 재사용하지 않는다.
- 작은 테이블 네 묶음은 PC 앞, 큰 흰 테이블 한 개는 ③ 브라우징 밸리 쪽에 놓는다. 큰 테이블의 6개 표식은 연결된 U자 소파에 배분한 임시 이용 지점이다.
- 창가 바는 오른쪽 짧은 곡선 창면에 놓고, 두 파란 소파는 타일 로비의 베이지 매트 위에서 사선으로 떨어진 구성을 표현한다.
- 개별 소파는 사진에 보이는 세 쌍의 6개만 반영하고 PC 반대편 오른쪽 직선 창면에 놓았다. 앞선 논의의 8개를 공식 수량으로 확인한 것은 아니다.
- 자유석 번호가 있는 42개 지점은 선택할 수 있다. PC 예약석은 선택·신규 이용·QR 생성·자유석 집계에서 제외한다. 다른 회색 가구도 번호 표식이 있으면 선택 대상이다.
- 공식 안내도와 VR에서 상대적 배치만 재구성했다. 정확한 거리·방위·실측 가구 치수를 확인한 도면은 아니다.
- 배치도 좌표계: 1200 × 1500. React 확대 범위는 100% 전체보기부터 최대 400%이며, 좁은 모바일 화면에서는 300% 이상 확대해 선택하도록 구성한다. PC 제외 수정본은 320–430px에서 활성 표식 42개·PC 표식 0개와 배경 로딩, 300% 선택 영역 크기를 확인했다. 공식 실측 도면의 정확도를 검증한 것은 아니다.
- 제작일: 2026-10-03 / 구성 수정일: 2026-10-04
- 현재 React 자리 화면은 이 구역을 사용한다. 앞선 ① 카페 전체층 안내도는 참고 자산으로 보존한다.

공식 사진과 곰두리는 수업·팀 내부 검토용 프로토타입에 활용한다. 학교 이미지의 권리는 원 제공처에 있으며, 외부 공개나 상업적 사용을 진행할 때는 제공처의 이용 조건을 확인한다.
