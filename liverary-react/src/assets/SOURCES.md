## UI 아이콘

- 저장 파일: `icons.svg`
- 제작: 프로젝트 전용 SVG 심벌 모음
- 표현: 홈, 좌석, 소식, 기록, 프로필, QR, 공유 등의 선형 아이콘
- 사용 위치: 메뉴와 버튼, 좌석 상태, 카드

공식 사진과 곰두리는 수업·팀 내부 검토용 프로토타입에 활용한다. 학교 이미지의 권리는 원 제공처에 있으며, 외부 공개나 상업적 사용을 진행할 때는 제공처의 이용 조건을 확인한다.
